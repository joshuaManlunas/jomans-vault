description: A self-hosted secret store for developers and their coding agents.
---

jomans-vault stores secrets for your projects and environments. Developers manage values in the web app and run local commands with the `jv` CLI. Coding agents get scoped API keys with only the access their work needs.

Start with a local vault, then choose how to give a machine or agent access. Read the security model before granting permissions that return plaintext.
